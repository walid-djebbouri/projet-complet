Kafka Apache

Définition

kafka apache est une plateforme de streaming distribuée
Kafka est un ensemble de machines travaillant ensemble pour pouvoir gérer et traiter des données infinies en temps réel

    La messagerie

  • Producteur : Qui produit et envoie les messages à une ou plusieurs files d'attente ;
  • File d'attente : Une structure de données tampon, qui reçoit (des producteurs) et délivre des messages (aux consommateurs)
    de manière FIFO (First-In First-Out).
    Lorsqu'un message est remis, il est définitivement supprimé de la file d'attente, il n'y a aucune chance de le récupérer ;
  • Consommateur : Qui est abonné à une ou plusieurs files d'attente et reçoit ses messages une fois publiés.

    • Chaque cluster contient plusieurs Broker et chaque Broker contient au moins un partition d'un topic cela veut dire
    qu'une partition d'un topic est répliqué sur plusieurs Broker pour garantir la maintenabilité du système
    et parmi les partitions répliqué il y a une seule partition considéré comme un leader et c'est la seule partition
    qui subi des opérations d'écriture les autres seront synchronisé avec le leader
    on cas ou la partition leader tombe en panne c'est au zookeeper de élire une nouvelle partition leader
