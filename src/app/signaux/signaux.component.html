Detecte Change Cycle

  • La détection de changement est le mécanisme qui permet à Angular de synchroniser le DOM avec l’état de la classe TypeScript.

  • La détection de changement se déclenche à chaque fois qu’un événement DOM survient, qu’une valeur d’entrée (@Input) change, qu’une requête HTTP reçoit une réponse, qu’un Observable émet une nouvelle valeur ou qu’une fonction de type setTimeout est exécutée.

  • Le ChangeDetectionStrategy.OnPush bloque la detection de changement en cas de changement de référence de @Input(), callback fonction comme setTimeOut , ou les observables qui n'utilisent pas le pipe Async pour gérer leurs abonnement

  • InputSignal est la combinaison du concept de Signal avec le décorateur @Input(), ce qui permet de recevoir des entrées réactives sous la forme d’un type InputSignal <T>

  • Pour créer un InputSignal il faut utiliser la syntaxe suivante

    1. prenom: InputSignal<string> = input('djebbouri', { transform: (prenom) => `${prenom}_hello` });



    2. et Pour utiliser ce InputSignal n'oublie pas d'ajouter des () dans chaque appel prenom()
