The Provider also tells the Angular Injector how to create the instance of dependency.
There are four ways by which you can create the dependency:
They are Class Provider (useClass),
Value Provider (useValue ),
Factory Provider ( useFactory ),

    How to implement IoC
          In object-oriented programming like Typescript, there are several basic techniques to implement inversion of control. These are:

          1- using a factory pattern
          2- using a service locator pattern
          3- using a dependency injection of any given below type:
              -a a constructor injection
              -b a setter injection
              -c an interface injection

      En termes simples, l'Inversion de Contrôle signifie que le contrôle sur le flux d'exécution d'un programme est inversé par rapport à la méthode classique de programmation.
    Au lieu que votre code principal soit responsable d'appeler des fonctions ou des méthodes d'autres composants, vous déléguez ce contrôle à un conteneur ou un framework.

      En résumé, l'Inversion de Contrôle est un concept qui consiste à déléguer le contrôle sur la création et la gestion des composants à un système externe. Cela améliore la modularité,
    la réutilisabilité et la facilité de maintenance du code. L'injection de dépendance est l'un des mécanismes couramment utilisés pour mettre en œuvre l'IoC dans la pratique.
